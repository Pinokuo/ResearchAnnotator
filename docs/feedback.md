# Beta feedback

Use [GitHub Issues](https://github.com/Pinokuo/ResearchAnnotator/issues/new/choose) in this same repository for Report a Bug, Request a Feature or Ask a Question. No separate distribution repository is used.

For a bug, provide extension version, Zotero version, OS, reproducible steps, expected/actual behavior and whether you can reproduce with a synthetic/public PDF. State whether the AI provider is local or external without sharing credentials. For capture/navigation issues, distinguish wrong attachment, wrong page and approximate passage location.

Redact screenshots and logs. Do not upload full profiles, databases, research-data exports, private manuscripts or API keys. Include small non-sensitive excerpts only when you have permission. Report security/privacy concerns through a private channel agreed with the maintainer rather than opening a public issue with sensitive details; a dedicated security address has not been designated.

For feature requests, describe your research task, current workaround and desired result. Support is welcome at [Buy Me a Coffee](https://buymeacoffee.com/researchannotator); donations do not change the beta's safety or compatibility guarantees.
