ResearchAnnotator Colors AI Chat Data Management General Each color has its own configuration, separately for highlights and for areas. A color left empty is ignored. No color is configured: ResearchAnnotator is inactive. Highlight Colors Expand a color to edit its fields and AI configuration. Drag the reorder handle, or focus it and use Arrow Up/Down. Archiving preserves history; permanent deletion is available only for unused colors. Highlights Areas (images, tables) Frame drawn around a figure, a table or part of a page. Displayed above the fields in the selection popup. 1 Fields Manual and AI fields are stored independently of native Comment. AI fields show their instruction editor when selected. Types, formats and text syntax Types: text (default), textarea, check, select (comma-separated options), multiselect (searchable multiple values), ai (written by the model from the instruction in the options column). Formats: bold, italic, bolditalic, underline, plain (default). Text syntax, one field per line: name | Label | type | options | format. Without options, the format may be given in the fourth column. heading | Heading | text | bold paraphrase | Paraphrase | textarea reference | Reference | text | italic summary | Summary | ai | Summarize the passage in one sentence. | italic Structured values are stored separately from native Comment. Each field is also a variable ({{name}}) usable in the prompt and the layout. Signed-in user and group identities work across devices; unsigned libraries require explicit mapping.
