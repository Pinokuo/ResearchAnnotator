# Feedback and contributions

The intended project is the existing independent `Pinokuo/ResearchAnnotator` repository, with development on main, integrated documentation and same-repository Releases/Issues. It remains private and the beta is unpublished. These files are a review staging area; no separate distribution repository is currently planned. Issues are already enabled but are not public while the repository is private.

- **Report a Bug:** use the bug template with OS, Zotero/extension versions, steps, expected/actual results and redacted diagnostics.
- **Request a Feature:** describe your research task, current workaround and desired result.
- **Ask a Question:** use the question template; explain what you tried and link to the guide section that was unclear.

Read [feedback guidance](docs/feedback.md) and [known limitations](docs/compatibility.md) first. Reproduce with synthetic or shareable material where possible. Do not post credentials, private PDFs, databases, profiles or research-data exports. Do not publish a security-sensitive report in a public issue; agree on a private channel with the maintainer.

Documentation corrections and clearer reproduction steps are welcome. Discuss a proposed change before doing substantial work. Once repository visibility is approved, source contributions can use feature/fix/docs branches and reviewed pull requests against main. Until then, no private-code access is implied. Keep contributions respectful, preserve licensing/attribution and make no new compatibility claims without evidence.
