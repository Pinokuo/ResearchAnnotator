# Installation

Use the canonical [five-minute installation and safe-upgrade guide](docs/installation.md). It includes the correct XPI, checksum verification, first semantic color/highlight/note and known beta limitations.

The repository is private and the beta draft is unpublished. No public download or automatic update feed is advertised. Back up Zotero and export research data before beta testing; older development builds should open Chat once before upgrading.

Developers: run the documented checks in [TESTING.md](TESTING.md) and use package-dev.ps1 for reviewed development packaging. Do not run inherited release scripts as an installation step.
